Numen — third-party libraries of the `mcp` module
=================================================

The `mcp` module implements the MCP server and client itself. Its OAuth client
(used when Numen connects to an MCP server that requires a login) is built on the
Nimbus libraries below: oauth2-oidc-sdk, nimbus-jose-jwt, content-type, lang-tag,
json-smart, accessors-smart and jcip-annotations. They are merged into the Numen API
jars on both loaders, with the packages `com.nimbusds`, `net.minidev` and `net.jcip`
relocated under `com.dwinovo.numen.mcp.shaded`, so that they cannot clash with the
older copies of these libraries that the game ships. The code is otherwise unchanged.
The texts below travel in every Numen API jar under `META-INF/third-party/` (this file
and the `third-party/` folder of `licenses/`).
