Numen — third-party libraries of the `mcp` module
=================================================

The `mcp` module (MCP server and client, OAuth) is built on the libraries below.
They are shipped unchanged: as nested jars in the Fabric and NeoForge jars of
Numen API (each nested jar keeps its own META-INF), and merged into the Numen API
plugin jar on Paper. The texts below travel in every Numen API jar under
`META-INF/third-party/` (this file and the `third-party/` folder of `licenses/`).

License texts (in `licenses/third-party/`):
  Apache-2.0.txt                    Apache License 2.0, full text
  MIT-mcp-java-sdk.txt              MIT License of the MCP Java SDK
  MIT-0-reactive-streams.txt        MIT No Attribution of Reactive Streams
  LICENSE-tomcat-embed-core.txt     Apache Tomcat's own LICENSE (Apache 2.0 plus the licenses of the
                                    components Tomcat bundles)

NOTICE files, copied verbatim from the META-INF of the jars that carry one:
  NOTICE-tomcat-embed-core.txt, NOTICE-tomcat-annotations-api.txt,
  NOTICE-jackson-annotations.txt, NOTICE-jackson-core.txt, NOTICE-jackson-databind.txt,
  NOTICE-jackson-dataformat-yaml.txt
The other libraries ship no NOTICE file in their jars.
