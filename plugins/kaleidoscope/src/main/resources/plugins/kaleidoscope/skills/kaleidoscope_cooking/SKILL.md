# 用森罗的厨房做饭

这个世界装了森罗物语:厨房。做饭的动作都在 `kaleidoscope` 命令组里:`recipes` 查菜单、`inspect` 看锅、
`cook` 做菜。每个动作怎么写,用 `kaleidoscope <动作> --help` 查;这里只讲什么时候用、怎么安排。

**配方永远现查,不要凭记忆报菜名。** 整合包能加菜也能删菜,而弹性配方的配比每个存档都不一样。

## 两口锅脾气不同

**炒锅**急。倒油开出来的下料窗口只有一分钟,炒好之后也只有四十秒能端出来——过了就糊,再放一会儿
整锅变成木炭。所以炒锅的菜要**人到了再开火**,别先起锅再去别处找碗。

**汤锅**稳。它不会糊,炖好了可以一直等着,而且一锅能盛出好几份——招待一桌人用汤锅最省事。
但它有三条死规矩:盖着盖子什么都放不进也盛不出;盖子一盖上、锅里又有料,立刻开炖;没火整个不动。

两口锅都要**底下那格点着**(灶、营火都行)。没火的时候锅是完全静止的,连倒计时都不走——
`inspect` 看到 `has_heat_source: false` 就别在那儿干等。

蒸笼、砧板、石磨、烤架这几样还没接上,你用不了,别答应主人做那些。

## 给主人安排一顿饭

1. 先问清楚或者自己判断:他是饿了要垫一口,还是要正经吃一顿。
2. 只看**现在就做得出来的**(比如 `kaleidoscope recipes pot --have_only true`),比翻整份菜单快得多。
3. 做得出来的里面挑:主食(饭)+ 一个菜就够一顿;人多就用汤锅出一锅。
4. `inspect` 确认那口锅是空的,`goto` 过去,再 `cook`。
5. 做完跟主人说一句做了什么、什么成色,别默默把菜塞给他。

一次只做一道。身体一次只做一件事,`cook` 是派下来的活,上一道的 `task_finished` 到了再派下一道。

## 料从哪来

森罗自己带了四种作物,种法和小麦一样——锄地、撒种、长熟右键收(收完自己退回半熟,不用重新播种),
**镰刀**(`kaleidoscope_cookery:sickle`)能一片一片割:

- **稻子** `rice_seed` — 要种在**水里**(泡水的耕地),长起来有两三格高,收的是稻穗,稻穗才能变成米饭
- **番茄** `tomato_seed`、**辣椒** `chili_seed`、**生菜** `lettuce_seed` — 普通耕地就行

**油**是炒锅的门槛,标签 `kaleidoscope_cookery:oil`。猪身上能得到油脂;油能压成油脂块收纳,
也能灌进油壶(`oil_pot`),或者用锅铲从搪瓷盆里蘸一铲带走。**没油就先去弄油**,别想拿别的油脂凑。

**容器**(碗、盘子)和**锅铲**、**锅盖**算厨具,`recipes` 每一行都写着这道菜要哪几样。
出锅时手里没容器,菜就端不出来,只能眼看着糊——备料的时候一起备。

## 黄金配比怎么用

有一部分菜(回执里写 flex recipe 的那些)**同样的料,投料比例不同,做出来的成色不同**:
生疏 / 普通 / 优秀 / 极佳,成色直接决定这道菜回多少饱食度、状态效果持续多久。

这个比例**由世界种子和配方一起决定,每个存档一套**。`recipes` 给你的份数就是这个存档的黄金配比,
`cook` 也照着它投——你不用自己算,但要记住三件事:

- **换了存档就作废。** 别把这一局的配比记进心里带到下一局,也别照着别人的攻略投。
- **看的是比例不是总量。** 2:1 和 4:2 是一个成色,所以料紧张的时候按小的那份投,不浪费。
- **只有一味料的菜怎么放都是极佳。** 放一份就够了,多放纯属浪费。

固定配方没有成色这回事,照着份数投就是那道菜。

## 出岔子

回执会直说卡在哪一步,照着那句话办就行,别猜:

- **缺料 / 缺油 / 缺碗** — 先去补齐再来。`recipes` 的 `have_only` 就是用来避免这种事的。
- **没火** — 把锅底下那格点着,或者换一口下面有火的锅。
- **锅被占** — 里面是别人的活。`inspect` 看它还要多久,等得起就等,等不起换一口锅,
  **不要把别人锅里的东西倒掉**。
- **够不着** — `cook` 不会自己走过去。先 `goto` 到锅边上再叫它,这和 `use block` 一样。
- **糊了 / 做出了黑暗料理** — 你会收到一条急件。别再端上桌,跟主人说清楚,要么重做要么换一道。
  炒糊多半是因为出锅时手里没容器、或者翻炒的时候锅铲丢了。
- **主人不许** — 那就是不许,换个做法或者问他想怎么办,别绕路。

## 分寸

- 做饭是给人吃的,不是刷成就。主人没说饿、也没说要做饭,就别自己开火霸着锅。
- 别把厨房当仓库清理。锅里的东西、台面上的盘子都可能是主人摆着的。
- 一道菜做完报一句就够:做了什么、什么成色、放哪了。不用汇报每一次翻炒。
