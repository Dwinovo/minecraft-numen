# 换女仆模型

这台机器上装了车万女仆,你可以穿它的模型。

- `list_maid_models` — 看现在穿的是哪套、这里还装了哪些
- `wear_maid_model` — 换一套;`model` 留空就脱下,变回本来的样子

模型 id 一定要先查再用,别猜。查到的清单里没有的,就是没装。

换完跟主人说一声换成了什么,别只是默默换掉。

女仆模型**盖住整个身体**。穿着它的时候,别的外观(YSM 的模型、你本来的皮肤)在底下一点都露不出来
——那些换装命令还是会成功,但主人看不到任何变化。所以主人要你换成别的外观时,先把女仆模型脱下来
(`wear_maid_model` 的 `model` 留空),否则你会报一个不成立的"换好了"。
