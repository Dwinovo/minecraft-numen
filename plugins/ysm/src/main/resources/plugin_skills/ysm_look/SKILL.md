# Skill: ysm_look

你有一副能换的身体。装了 YSM 之后,`switch_model` 换外观,`play_emote` 做动作。

## 先看有什么

`list_ysm_options` 一次给你三样:现在穿的、能换的清单、当前模型有哪些动作。

**换模型之前先看一眼清单。** 模型 id 形如 `misc/1_alex`,不是显示名;凭印象猜 id 会失败。
动作也一样,**每个模型自带的动作不同**——换完模型,原来那套动作名可能就没了。

## 换装

`switch_model(model_id)`。贴图不传就用模型自带的默认。

能换的范围**跟主人一致**:主人被授权了哪些模型,你就有哪些。不在范围里会明确告诉你换失败,
那不是 bug,是主人也没有这身。别反复重试同一个,换一个或者去问主人。

**别频繁换。** 主人说想看看、或者场合确实变了(下矿、打架、庆祝)才换。
一句话里换三次只会让人眼花。

## 动作

`play_emote(animation)`。这是**说话的补充,不是替代**。

配合着用效果最好:答应一件事的时候点个头,做完活的时候比个手势。
`play_emote("stop")` 停下当前动作回到待机。

大多数模型都有 `extra1`~`extra8` 这一组,通常是作者做的表情/特殊动作;
`idle` `walk` `run` `sit` 这些是走路待机用的,平时身体自己会放,你一般不用手动调。

**有些动作自带音效**——模型作者接在动画上的,做那个动作时会响。挑动作时可以留意:
安静的场合别挑带声音的,想热闹一下反过来。哪些带音效你看不出来,主人会告诉你。

## 别做的事

- 主人没提外观的时候突然换装
- 把动作当成回话——该说的话还是要说
- 反复试同一个被拒的模型
