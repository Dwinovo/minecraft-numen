# 0009 皮肤由挑的人的客户端签好交给服务端,服务端只验签和穿上

- 状态:已接受,已落地
- 日期:2026-11-25
- 修订:[0005](0005-skins-are-pngs-in-a-folder-signed-on-use.md)(签名只在服务端、签名缓存在服务器目录)
- 另见:[0008](0008-brain-on-owners-client.md)(服务端要用的放服务端,只有一端用的放那一端)、[0007](0007-paper-removed.md)(默认玩家装了客户端)

## 背景

0005 把签名放在服务端:玩家把 png 传给服务端,服务端排一条队交给 MineSkin,签好按图片哈希存进服务器目录下的缓存,再给她穿上;
MineSkin 的 key 在服主的钥匙串里。大脑搬回主人的客户端(0008)之后,这样分出了毛病:

- 界面上填的 MineSkin key 进了玩家自己电脑上的钥匙串,服务端签名读的是服务器的钥匙串:单人游戏里填了也用不上,专用服上界面里设不了。
- 服主要替所有人出 MineSkin 的额度,专用服上还得决定谁有权设这把 key。
- 为了签名,服务端要替玩家联网:取网址上的图、查正版玩家、发 MineSkin。

用户:"我个人倾向于客户端,因为这是玩家自己的事情。"

## 决定

心智模型:**签名是谁挑谁做的事。挑皮肤的那个人的客户端拿到原图、签好,把签好的皮肤数据交给服务端;服务端验过 Mojang 的签名就给她穿上。**
判据照 0008:服务端要用的是签好的那份数据(穿到她身上,大家都看得到),所以它在服务端;拿图、签名、key、缓存只有签的那一端用,所以都在客户端。

1. **两端各管什么。**

   | 挑皮肤的人的客户端 | 服务端 |
   |---|---|
   | 拿原图:本机皮肤文件夹、服务器皮肤文件夹(向服务端要原图)、网址、正版玩家名 | 服务器皮肤文件夹:列文件、按名字给原图 |
   | 判断粗细(`SkinVariants`) | 验签:签好的数据是不是 Mojang 签的 |
   | 签名:MineSkin(他自己的 key,没填走匿名额度);正版玩家的皮肤本来就是 Mojang 签好的,不经 MineSkin | 穿上:换她的身体,名册里记签好的数据与引用(`SkinRef`) |
   | 签名队:限流时等、排第几,只排他自己的 | |
   | 签名缓存:按 `SkinRef`(原图内容哈希 + 粗细)存签好的结果,同一张图同一粗细只签一次 | |

2. **穿上只有一个入口,在服务端。** 客户端交来"她、引用、签好的皮肤数据(value 与 signature)",服务端先用 Mojang 的服务公钥
   (服务器启动时原版就取好的那一套,authlib 的 profile property 公钥)验签,验过才换身体、记名册;验不过或取不到公钥,拒绝并说明原因,
   不穿未签名的数据,也没有第二条路。脱掉走同一个入口。引用只给主人的界面对"她穿的是不是这一张",服务端不拿它找任何东西。
3. **客户端里也只有一条流程**:拿到原图 → 查本机缓存 → 没签过就签 → 交给服务端穿上。皮肤选择器和召唤卡都走它;召唤卡上选的皮肤,
   和召唤卡上的其他绑定一样,由主人的客户端在她到了以后穿上。
4. **签名队、签名缓存、MineSkin 与 Mojang 的联网、key 属于这台电脑**,跟着 `ClientMachine` 走,不跟着某一条连接:换服务器缓存照用,
   key 在这台电脑唯一的钥匙串里。
5. **删掉的**:
   - 服务端的签名队、服务端签名缓存(`skin-cache/`)、服务器钥匙串里的 MineSkin key。服务器上不再有任何 key。
   - 服务端替签名联网取图与查正版玩家的那几条。
   - `/numen companion <她> skin …` 命令。它是给没装客户端的玩家准备的(0007 之后没有这种玩家),皮肤选择器是唯一的入口。
   - 服务端推给主人的签名排队状态。排队在他自己电脑上,界面读本机。
   - 召唤卡随召唤上传原图那一段。

## 后果

- 每个人用自己的 MineSkin 额度;没填 key 的人走匿名额度,排得慢一些。服主不再出这份额度,也不再管谁能设 key。
- 同一张图,每台电脑签一次,不再是整台服务器签一次。MineSkin 对同一张图本来就会给出同一份签名,多签几次不费额度。
- 网址、正版玩家名走玩家自己电脑的网络与代理;服务器连不上 Mojang 也能给她换皮肤,只要它取得到验签用的公钥。
- 服务器上已有的 `skin-cache/` 不再读,也不写迁移:她身上已经穿着的照常穿着(签好的数据在名册里),换皮肤时由客户端重新签。
- 改过的客户端最多能给自己的同伴穿上一份真的、Mojang 签过名的皮肤,伪造不了签名。
