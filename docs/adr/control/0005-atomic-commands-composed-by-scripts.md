# 0005 一条命令只做一件事,组合交给脚本

- 状态:已接受;组合语言起初定为 bash 子集,同日改为 Lua([0006](0006-lua.md))
- 日期:2026-10-01
- 提交:`b53caf0e6`、`0ccaff2c1`、`9545368bd`
- 另见:`docs/shell.md` §一 – §三、`docs/architecture-mind-model.md` §零

## 背景

真模型评测的基线里,命令写错是最常见的问题(`work_dig` 的位置写成一整串、`fight attack` 漏了参数……):她照 bash 的习惯写,是我们的写法不像 bash。
另一面,`work dig`、`build at` 这类胖命令在执行里替她做决定,违背总纲"她看一眼很贵,会改世界的决定要提前可见,执行里不替她拿主意"。

## 决定

- **原子判据**:一条原子命令 = 对一个对象做一种意图;可以含完成它必需的动作层控制(对准、换工具、清掉挡着它的格),不在几种会改世界的方案之间替她选,
  不碰对象以外的东西。挖只挖、寻路只寻路、移动只移动。
- **没有不可拆的行为**(用户纠正):秒级的决策循环(打哪只、按什么顺序、何时撤)进脚本,每刻要转的控制(追着转头、等冷却出手)进原子命令内部,安全兜底由反射打断。
- **命令行十条**(POSIX 工具语法、GNU 长选项、clig.dev):`组 动词 [对象...] [--选项 值]`、一种位置参数、对象写法全局一处解析、不要必填选项、
  开关不收值、`error:`/`usage:`/`hint:` 三段报错、帮助由登记生成、时长统一秒;**写进登记处,违反就启动报错**,插件同样受约束。
- **组合交给脚本**:流程固定的活写成随模组发布的内置脚本,她读得到、改得了,也能自己写、自己存。第一版定的是 bash 子集(模型最熟的 DSL)。

## 后果

- 胖命令拆成原子命令加内置脚本(挖一团矿 = 走到够得着 + 挖 + 捡)。
- 合回的门槛定为真模型评测追平基线。
- 当天用户问"为什么不做 lua 呢":bash 子集与 Lua 会是两套组合语言,改为 Lua(0006)。
