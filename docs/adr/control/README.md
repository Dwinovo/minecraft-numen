## 沿着一件事看

- **工具数量**:0002 每个能力一个工具(45 个)→ 0003 渐进披露(失败)→ 0004 一个命令工具(12 个)→ 0008 `[lua, skill, todo, memory]`。
- **谁掌控工作流**:0002 工作流是黑盒 → 0005 原子命令,组合交给脚本 → 0006 图灵完备的 Lua → 0008 胖命令拆成出厂 Lua 库,她看得见、改得了。
- **状态放哪**:0004 命令行无状态,名词存磁盘 → 0008 Lua 不留状态、世界就是状态,要记住的只走 memory。
- **在哪一端跑**:0008 程序在主人客户端 → 0010 整段在服务端 → 0011 循环与记忆也去服务端;往后见 runtime。
