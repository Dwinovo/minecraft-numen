# 0003 工具渐进披露

- 状态:被取代(09-20 删除,工具表发全份;之后由 [0004](0004-command-line.md) 解决工具数量)
- 日期:2026-08-26
- 提交:`012073ee7`;删除 `471d3861d`

## 背景

45 个工具的完整定义每轮全发,其中大半整轮用不上(control 0002)。

## 决定

常驻 11 个(感知、轮询、移动、规划),其余在系统提示的 `<deferred_tools>` 里留一行摘要,模型调 `find_tools` 取回完整定义;
展开物走消息流,不进请求前缀。

## 后果

- 玩家反馈效果明显变差([#109](https://github.com/Dwinovo/minecraft-numen/issues/109),@murasaki44);机制没做好,也容易破坏缓存。
- 09-20 删掉,工具表一律发全份(提交署 murasaki44 为合作者)。
- 只给名字也撑不住几百个工具;这个问题交给命令行(0004),按模组为单位渐进加载。
