# 0001 一只同伴一个智能体

- 状态:已接受
- 日期:2026-05-29
- 提交:`d6d797ffa`(05-18)、`a84cf3c0d`

## 背景

05-15 起每只同伴有一个 ReAct 循环。05-18 照 opencode 的任务工具与子智能体改成两层:每位玩家一个 `PlayerAgent` 当大脑(只出策略、派任务),
下面六个 `EntityAgent` 单位各领一次任务、做完汇报。

## 决定

退回一只同伴一个长期对话,主人直接和她说话:她拿全部工具、带人设、跨多次提问存活。上层调度等单个智能体调稳了再说。

## 后果

- 一只同伴的行为从头到尾在一个对话里,好调试。
- 之后的一切(工具、命令行、Lua、群聊)都在"她自己的一个循环"上长出来;多人对她说话是群聊(收件箱里分人),不是多个智能体。
