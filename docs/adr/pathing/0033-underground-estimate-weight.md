# 0033 地下的失败:估价松在水平项,权重取 4

- 状态:已接受;改 [0032](0032-simplification-audit.md) 里"权重不动"一行,改 `AStar.WEIGHT` 的出处([0001](0001-astar-over-moves.md) 起沿用的 2.5)
- 日期:2026-10-31

## 背景

规划评测 dev 上,规格 B 的地下中长距离题(洞穴、空腔、封闭的一格)成功率只有三成多,失败的 44 行里 29 行一格没挖,搜索把地表泛洪到总预算用完。
先问估价是不是不准,再问怎么办。

## 诊断

对这 74 道题(到了与放弃的,中长档、非地表)用标准答案的求解器(权重 1,节点上限 2 000 000)量**起点估价 ÷ 最优价**:

| | 到了 | 放弃(答案有最优价的 9 道) |
|---|---|---|
| 起点估价 ÷ 最优价,中位 | 0.55 | 0.31 |
| 水平项 ÷ 最优价,中位 | 0.33 | 0.27 |
| 埋深项 ÷ 最优价,中位 | 0.00 | 0.00 |
| 升降项 ÷ 最优价,中位 | 0.02 | 0.02 |

- 缺口全在水平项:直线疾跑下界不知道洞穴要绕、墙要绕,最优路线是直线的三倍多。埋深项与升降项本来就几乎是零——
  这批题不少不是"要挖穿很多石头",而是"洞穴网络里绕很长的路";埋深的松弛让空气格不要钱,洞穴一连通到起点跟前就是零。
  埋深的格数上限(`cap`)不是原因:上限 20 万与 200 万两档,74 道题的埋深值一道也没变。
- 把埋深或升降算得更紧,补不了这个缺口。要补的是"绕路"——水平项要知道地形的拓扑,而那是一遍搜索本身的活;
  0029 的按列图只管水,评测上中性,0032 已经删了。
- 权重大一点,是估价松时的常规办法:Baritone 取半程的系数表一路到 10。28 道在标准答案那里 200 万节点权重 1 与权重 2.5 都搜不出,
  更不是估价能一下补上的。

## 决定

`AStar.WEIGHT` 2.5 → 4。dev 668 行、封存 876 行(同一棵树,同样的评测,计数时钟):

| 权重(dev) | 2.5 | 3 | 4 | 5 | 8 |
|---|---|---|---|---|---|
| 规格 B 到达 | 258 | 261 | 267 | 266 | 270 |
| 规格 A 到达 | 163 | 163 | 162 | 162 | 162 |
| 地下中长(A+B)到达 | 38 | 41 | 45 | 42 | 45 |

取 4:B 的增益在 3 到 8 之间已经平了,再大只多路线更长、规格 A 一直是 ±1。

- **规格 A 不退步**:到达 163 → 162(dev,中距离一行),封存 217 → 217;它们不挖不垫,权重大了没有可多拿的,也没有被拖累。
  A 的成功率数字掉(74.1% → 72.3%)是分类变化:权重 4 下搜索不再逮着区域边缘走,"区域外"的行少了,落回"放弃"里;到达的数不变。
- **地表**:地表题到达 dev A 137 → 137,B 197 → 199;封存 A 171 → 171,B 267 → 272。
- **延迟**:起步 p90 不变或更低(dev 规格 A 长档 139 → 20,B 长档 200 → 156);单次最长思考 p90 有升有降,升的两处:dev 地表 A 短档 876 → 1205 ms、
  封存非地表 B 短档 1752 → 2348 ms;降的更多(dev 地表 A 中档 2596 → 1184 等)。
- **代价是路线**:规格 B 趟总耗时 +12%(dev)与 +14%(封存),是走更长的路,不是想得更久。
- 更早的 27 条手挑路线上扫过 4 与 8,到达不变、中距离路线价高 21% 与 32%(`AStar.WEIGHT` 旧注释)——那批路线估价本来就紧,权重帮不上,现在的题集里才看得出。

## 为什么 0032 说 2.0 与 2.5 同

那是同一条曲线的平段(0032 那棵树上 B 到达 2.0 是 256、2.5 是 255;这棵树上 2.5 是 258、3 是 261、4 是 267),增益在 3 以上才出现,2.0 与 2.5 之间只差 25%,落在噪声里。
和半程去处、Columns 无关:在 0032 之前的树上(半程按 g+h、Columns 还在)只改权重到 4,B 就是 255 → 263,地下 37 → 42;与半程去处 `g + 5·h` 同用 266,各自的增益相加不到一起(+8、+5,合起来 +11)。

## 没解决的

- 规格 A 的 6 个真失败(4 个标准答案证明区域内无解的森林题,2 个能到的洞穴题 caves-medium-026、caves-long-028):前者是"证明到不了"没证出来,后者是 A 下的洞穴。
  权重 4 下它们的结果没变,估价一栏也帮不上(不挖不垫的 A 里埋深项恒为零)。
- 估价缺的"绕路",要有地形拓扑的水平项才补得上,代价是一遍近似的最短路(0029 的路),且要覆盖洞穴而不止水。
