# 0010 搜索预算按展开节点数

- 状态:被 [0026](0026-search-clock.md) 取代
- 日期:2026-09-25
- 提交:`f37c5600f`、`5f430e9ad`

## 背景

按墙钟的预算(0006)让同一个请求的结论随机器负载漂移,真机上"没有路"时有时无,复现不了;几处搜索各自派发,"规划在飞"要问好几个地方。

## 决定

预算按展开的节点数;所有导航的搜索经同一个派发口;搜索结论带停因(预算用完不再说成没有路)。

## 后果

- 同一世界、同一起终点、同一规格得到同一结论,靶场能逐字节复现(0013)。
- 每个节点的价钱直接决定一段搜索要多久,性能要靠把节点做便宜(0019),不能靠放宽预算。
