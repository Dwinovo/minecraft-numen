# 0001 在走法图上做 A*,会挖会垫

- 状态:已接受(做法沿用至今,内核换过几次,见 0002、0004、0007、0011)
- 日期:2026-05-29
- 提交:`0182110cf`、`ba853b667`、`37dba187d`

## 背景

同伴当时是一只生物(`AnimusEntity`),`move_to` 用原版 `PathNavigation`。它不会挖、不会垫,遇到一道坑、一堵墙就失败,
而她要做的活(挖矿、去主人身边、建造)几乎都要穿过这些地形。

## 决定

在"走法"组成的图上做 A*:平走(顺带搭桥、挖开头脚两格)、上一级(挖净空、垫台阶)、下一级与下落;06-03 照 mineflayer 补斜走、垫柱、向下挖。
代价按刻计,按她身上真带的料与工具算(没料就不出搭桥的边)。预算一万个节点,到不了交"离目标最近的一截",边走边搜。

## 后果

- 她能挖穿、垫过原版寻路过不去的地形。
- 一次搜索起初在主线程上跑,按时间切片分到多刻(每刻 1500 个节点),搜索的开销直接压在服务器刻上(后来挪出主线程,见 0003)。
- "交最好的一截"从这里开始,之后每个内核都要回答"交哪一截、什么时候放弃"(0004、0015、0020)。
