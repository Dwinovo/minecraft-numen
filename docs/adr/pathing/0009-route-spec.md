# 0009 路线规格:按次传值的 RouteSpec

- 状态:模块里的规格沿用;给模型的旋钮(`costs`、计划承诺、`plan_route`)被 [0016](0016-model-says-where-only.md) 取代
- 日期:2026-09-14
- 提交:`0b681889c`、`fc79a027f`、`52d5fa109`、`8ff502e8e`;`a05355864`(10-03)

## 背景

`TerrainPermit`(0008)只有"许不许改地形"一个开关;格子能不能站、能不能穿散在几处;模型想先看路线、再决定走不走,没有办法。

## 决定

- 路线规格 `RouteSpec`:按次传值、不可变,每次搜索与执行各带一份,成本模型只认它。四组谓词各一个出处:格子类型与每类代价、能力开关与上限、
  按位置的代价(`PositionCosts`)与按种类的禁令、动作代价。格子分类收成 `CellClass` 一处。
- 规划是查询:`RoutePlanner`、`RouteBook`、`plan_route`,模型可以先拿候选路线再走。
- 10-03 改地形拆成挖、放、征询三个开关。

## 后果

- 规格成了寻路唯一的输入口径,沿用到现在的模块里。
- 给模型的旋钮越来越多(`costs`、`avoid`、`arrive`、计划承诺),"能不能动"在工具、计划、权限层三处判;0016 把给模型的接口收回到"去哪、多近算到"。
