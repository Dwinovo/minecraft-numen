# 0008 走路不改世界,挖放要模型点头

- 状态:被 [0009](0009-route-spec.md) 取代
- 日期:2026-08-23
- 提交:`fdec57ab8`、`72ea34016`

## 背景

寻路默认会挖会垫(0001),她为了抄近路在别人的地上挖坑、垫柱,主人与模型都不知道。具身导航的调研结论:LLM 定去哪、许不许,导航栈自己不改环境。

## 决定

走路默认不挖不放(`TerrainPermit`);要挖放得由模型在调用时明确许可,回执照实记下挖了、放了哪些格。跟随跟不上就以结果收场,可以带许可开路。

## 后果

- 她不再擅自改地形。
- "能不能动这一格"从此在工具参数里判,和后来的权限层成了两处(0016 收回到权限层一处)。
