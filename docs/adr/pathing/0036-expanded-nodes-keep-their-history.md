# 0036 展开过的节点不再换走到它的历史

- 状态:已接受;改 [0024](0024-lazy-evaluation.md) 里节点松弛的一处(展开过的节点不再被更便宜的路径改写)
- 日期:2026-11-01

## 背景

挖掘罚分扫描(`breakPenalty` 30/10/2)里,罚分 2 的评测在两行(water-medium-037 B、forest-medium-006 B)上抛 `IllegalStateException`:
交路线时 `AStar.maneuver` 补一个快判断答"成立"的步子,在父节点此刻的世界上精确重判,得 `Fails`(例:`ASCEND` `TOO_HIGH`)。线上这会中断那次搜索。

## 诊断

只跑这两行、罚分 2,两次都稳定复现;罚分 30 下这两行不崩,罚分 30 与 10 的 dev、封存全量日志里也没有同类(标准答案的求解器也在罚分 30 下解完了这两行)。

在抛出处记下父节点展开时与现在的两份状态,同一个父节点(250,4,193):

| | 展开子节点时 | 交路线时 |
|---|---|---|
| 站姿 | GROUND、脚高 4、托脚 3 | 同 |
| 它自己的 g | 243.98 | 243.98(没变) |
| 父链(往上) | 14270(g 231.98)← 12328 `PILLAR` ← 12321 `PILLAR` ← 9700 | 14270(g **230.98**)← **22575 `ASCEND`** ← **13951 `ASCEND`** ← 9700 |
| 最近 8 步改动 | 垫 (251,0,192)、挖 (251,3,192)…… | 垫 (250,0,192)、挖 (250,3,193)、挖 (250,2,193)…… |

祖先 14270 在父节点展开之后被更便宜的路径走到(g 少 1.0),`relax` 改写了它的 parent、via、stance,父节点没有重新松弛,留着陈旧的 g,
子节点(快判断答成立,没有 `Maneuver`)是按旧历史判的。交路线沿现在的 parent 指针走,混进了新历史。

这是**状态混叠**:后继的前提读的是"走到这个节点的最近几步的改动"(`recentEdits`)与站姿,可节点的键只有位置、已改格数、憋气档,
展开过的节点被改写之后,它的后继依赖的那部分状态换了,后继却还指着它。主流 A* 的前提是后继只依赖状态本身(Baritone 的 PathNode 键只有位置,
因为它的走法只依赖位置加快照)。

## 两种修法

- **A**:展开过的节点不再换父节点,`relax` 对它直接返回。估价一致时加权 A* 不必重开,每个节点至多展开一次,路线至多比最优贵权重倍(ARA*,
  Likhachev、Gordon、Thrun 2003)。
- **B**:被更便宜的路径走到的已展开节点另起一个新节点(同一格同一档),旧节点留着给它的后继;后继依赖的历史随节点保存。

同一份评测(SLACK 10),罚分 30 对照现状(括号里是 dev / 封存):

| | 现状 | A | B |
|---|---|---|---|
| 到达 | 507 / 701 | **515 / 712** | 500 / 700 |
| 放弃 | 34 / 45 | **25 / 30** | 39 / 46 |
| 展开总数(万) | 3288 / 4055 | **2547 / 2956** | 3394 / 4058 |
| 单次最长思考 p90(ms) | 514 / 512 | **301 / 274** | 515 / 500 |
| 都到达的行里路线价合计 | 599260 / 892490(各自) | +1.3% / +0.8%(更贵的 213 / 260 行,更便宜的 68 / 70 行) | 约持平 |

罚分 2:现状 520 / 717(各有一行崩溃算放弃),A 525 / 722,B 519 / 714。A 与 B 在两个罚分下都不再崩溃。

权重 1 的标准答案求解器在短、中档两个规格各 12 行(每块地)共 132 行上,价钱与现状逐位相同:估价一致时没有需要重开的节点,A 不改最优价。

## 决定

取 A:一行改动,不加新结构,节点更少,到达更多;代价是路线价平均贵 1% 左右(加权 A* 本来就只保证权重倍以内)。B 要给哈希表加"顶替"、旧节点留着占内存,
节点数不降,到达反而少。不留两套。

## 没解决的

随机小世界上低罚分扫了 5500 个种子(一格高的石头、洞、挖到某格),交路线的抛出与"前序改动全叠上之后不成立的步"都没有复现:这个混叠要在大搜索里
(展开几十万节点、祖先被反复更新)才碰得到,所以没有单测,回归靠评测里那两行(罚分 2)。
