# 0017 估价 = 疾跑底价 + 额外代价下界,不多估

- 状态:已接受
- 日期:2026-10-11/12(0.1.5 第 8 步,六批)
- 提交:`9b78efd2e`、`069177f9e`;判据出处见 `pathing.md` 第六节第 17 行

## 背景

0016 的回归、水里估价偏低三倍(`long_300` 十一万节点)、半程挑法换不动,根都在估价离真实代价太远、f 等值面太宽。
诊断(不改行为)量出:平地疾跑稳态实际/最短 1.002,差在上下台阶与重复搜索,不在估价的平地部分。

## 决定

- 估价 = 水平距离 × 疾跑一格(`Goal.estimate`)+ 绕不开的挖掘(埋深 `Burial`,09-30 起)+ 升降 `Vertical`(按层查"这一层有什么上法",往下按"若干次落脚"的最小和)。
  每一项都是放宽问题的解,不多估,A* 仍找最优。
- 每种目标必须交代终点格与高度范围(`Goal.endCells()`、`heights()` 去掉默认实现),没有固定终点的明确交 null——忘了实现就悄悄少算一块的路堵死。
- 估价的开搜开销按层读、问到哪层读哪层。

考虑过:放宽估价(不可采纳,换速度);调预算;LRTA* 式学习与粗层(留到后面,见 0020、0021)。

## 后果

- `hill_detour` 一次搜到底 13007 → 2216 个节点、实走 1460 → 423 刻;往正下方 20 格 711150 → 135 个节点;打怪下 20 格 291724 → 314;靶场小搜索开搜 11.2 → 0.6 毫秒。
- `EstimateConsistencyTest` 逐节点逐方向断言估价的下降不超过真实代价,`GoalEndsTest` 把所有目标列成表核对。
- 水里与"空气连着但走不通"(洞穴、峡谷、盆地)仍松:第 9 步量出 `cave_far` 起点估价 ≤ 最优的 0.04、`ravine_floor` 0.13。
