# 0006 搜索预算按墙钟

- 状态:被 [0010](0010-node-count-budget.md) 取代
- 日期:2026-07-17
- 提交:`d6256efb9`

## 背景

学习表退役(0005)之后,洼地类地形靠预算搜完。按节点数的预算在快慢不同的机器上买到的时间不同,要逐机调参。

## 决定

预算按时间:主搜索 500 毫秒、失败的搜索 2 秒,另加 50 万个节点的保险丝;测试里仍用确定的节点数。

## 后果

- 同一时间在任何机器上买到它能探索的量。
- 同一个请求的结论随机器负载变:忙的时候搜得少、更容易报"没搜到"。09-25 改回按节点数(0010)。
