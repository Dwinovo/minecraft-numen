# 0025 一次朝真终点的加权 A*:去掉分段与贪心两遍

- 状态:已接受;取代 0020 第 1、2 条
- 日期:2026-10-28

## 背景

0020 每段只搜到"估价低 32 格"的节点、每段先贪心拿上界再加权证界。节点贵时这是省预算的办法;代价是可挖时交出的多半就是贪心那条"直挖直垫",
而且每段朝"看起来更近"的地方冲,冲进死胡同。惰性评估(0024)之后节点便宜了,这两套机制不再值得它们的复杂度。

## 决定

1. 一次搜索的目标就是真终点。终止只有三种:到了目标、时间到(0026)、搜空(能到的都搜过)。删除"段终点"(估价降一段)的判据。
2. 只跑一遍加权 A*,权重 w 在靶场上扫定。删除贪心一遍、以已有解剪枝、证界停与"证到的界"这份结论。
3. 没到目标时交半程,去哪由 `HandOver` 按 LSS-LRTA* 定:边界上总价最小、只截到回得了头的节点(0020 第 3 条;0027 试过洼地回避,不采纳)。
4. 快照半径不写死,按靶场量出的拷贝耗时与收益定。
5. 估价不变(0017):疾跑底价 + 埋深 + 竖直 + 这一趟抬过的增量。

## 依据

Baritone 与 mineflayer-pathfinder 都是一次朝终点、时限内交最好的半程;加权 A*(Pohl 1970)。没采用 TBA*(Björnsson, Bulitko, Sturtevant 2009):
它让一棵树从固定起点一直长,假设世界静态、内存不封顶,和"每次搜索一份快照、世界会变"不合。没采用 D* Lite:惰性之后重规划本身便宜,
它要求整趟共用一份可修改的图,和快照冲突。分层(0021)仍暂停,平层搜够不够看数据。

## 后果

- 删除 0020 的段长、每段节点数、贪心节点数、证界间隔等常数。
- 半程交出之后马上从半程终点接着搜(0026),段与段之间不停顿的要求不变。
