# 0025 一次朝真终点的加权 A*:去掉分段与贪心两遍

- 状态:已接受;第 1 条被修订(10-29);取代 0020 第 2 条
- 日期:2026-10-28,修订 2026-10-29

## 背景

0020 每段只搜到"估价低 32 格"的节点、每段先贪心拿上界再加权证界。节点贵时这是省预算的办法;代价是可挖时交出的多半就是贪心那条"直挖直垫",
而且每段朝"看起来更近"的地方冲,冲进死胡同。惰性评估(0024)之后节点便宜了,这两套机制不再值得它们的复杂度。

## 决定

1. ~~一次搜索的目标就是真终点。终止只有三种:到了目标、时间到(0026)、搜空(能到的都搜过)。删除"段终点"(估价降一段)的判据。~~
   **修订(10-29)**:估价仍按真终点算,终止多一种——到了这一段的终点:弹出一个相对目标的估价(不含这一趟记忆里抬高的增量)比这次起点低 Δ 的节点(没憋着气)就交出到那里的整截,
   身体边走边从那里接着搜。判据只在 `AStar` 一处;Δ 对所有距离一样,取 64 格疾跑的耗时。段内仍是一遍加权 A*、惰性精判,时间到了
   还没到段终点照旧交半程(第 3 条)。见下"修订的依据"。
2. 只跑一遍加权 A*,权重 w 在靶场上扫定。删除贪心一遍、以已有解剪枝、证界停与"证到的界"这份结论。
3. 没到目标时交半程,去哪由 `HandOver` 按 LSS-LRTA* 定:边界上总价最小、只截到回得了头的节点(0020 第 3 条;0027 试过洼地回避,不采纳)。
4. 快照半径不写死,按靶场量出的拷贝耗时与收益定。
5. 估价不变(0017):疾跑底价 + 埋深 + 竖直 + 这一趟抬过的增量。

## 依据

Baritone 与 mineflayer-pathfinder 都是一次朝终点、时限内交最好的半程;加权 A*(Pohl 1970)。没采用 TBA*(Björnsson, Bulitko, Sturtevant 2009):
它让一棵树从固定起点一直长,假设世界静态、内存不封顶,和"每次搜索一份快照、世界会变"不合。没采用 D* Lite:惰性之后重规划本身便宜,
它要求整趟共用一份可修改的图,和快照冲突。分层(0021)仍暂停,平层搜够不够看数据。

## 修订的依据(10-29)

- **不分段**(10-28 落地的样子):靶场 27 条可达路线到了 25 条(洞穴远处、三百格长路没到),搜索总耗时中距离是 9781232e8 的 4.7 倍、长距离 37 倍(对比外挂 B 规格整趟 38.4 秒对 3.9 秒):
  远处的一次搜索朝真终点铺开,一次就把时限与节点上限用满,交出的半程只有几步。
- **贪心先行**(按时钟重做 0020 的"先贪心拿上界再加权"):可挖时贪心那遍交出的多是直挖直垫,空手挖石头的路线贵出几倍,不恢复。
- **分段、在时钟下**:Δ 扫过 32、64、96 格疾跑——靶场三者都到 26 条,三百格长路都到了;64 与 96 的搜索总耗时比 32 少四成、路线价低一成,
  开始走的中位延迟三者都在 16–27 毫秒;96 格时难路上一段要搜得更久。取 64。权重在分段之后又扫过 4 与 8:到达不变,
  中距离路线价合计高 21% 与 32%,仍取 2.5。
- **一趟的总预算**按"段数 × 每段典型量 × 余量"(`Allowance`:至少 4 段、每段两万个节点、5 倍),数取自同一批靶场数据。
- **仍没到的一条**:洞穴远处(目标在地下五十多格)。估价里往下挖的价钱远低于空手挖石头的真价,加权 A* 在地表铺满时限也找不到
  估价低一段的节点;段长、权重(2.5/4/8)、不限总预算都试过,都没到(不限总预算时一路学习、绕进水下憋不住气收场)。9781232e8 靠贪心那遍
  直挖下去到的(路线价是 Baritone 那条在我们模型里价钱的近两倍)。留作已知缺口。
