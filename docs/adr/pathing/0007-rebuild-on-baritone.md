# 0007 新内核,再照 Baritone 写一遍

- 状态:被 [0011](0011-standalone-module-rewrite.md) 取代
- 日期:2026-07-18
- 提交:`01b42439b` … `1511b579e`、`f91c58a83`

## 背景

引擎 v2(0004)去掉学习表之后,剩下的走法、执行仍是一个月来补丁叠补丁的状态;执行层"对空跳、踩空、垫柱自锁"一类问题不断。

## 决定

在 `pathing-rebuild` 分支上按 Baritone 的结构重写一个内核:成本模型与 4097 项坠落表、方块判定库 `MovementHelper`、`ToolSet`、每次搜索的上下文;
22 个方向的走法各是一个状态机(规划与执行写在一个类里,照 Baritone 的 `Movement`);九种目标;A* 带七档半程、双轨超时与 Favoring;
执行器重定位、脱轨看门狗、代价复核、疾跑决策;段规划状态机。旧内核(引擎 v2、旧走法与执行、工作区里写了一版的粗层 `hier/`)整包删除。

## 后果

- 之后两个月(07-19 到 09-26)的提交大多是"规划与执行对不上"的个案修补:规划查手写的分类表 `CellClass`,执行按真实碰撞箱走,
  一不一致就在某个走法里补一条。
- 09-27 真机一局把这类问题集中暴露出来,促成 0011。
