# 0005 学习表退役,搜索纯确定性

- 状态:学习这一半被 [0020](0020-segments-learning-closed-loop.md) 取代(LSS-LRTA*,做法不同);"同一世界同一起终点得同一计划"沿用
- 日期:2026-07-17
- 提交:`15fc675a6`、`d6256efb9`、`d26e9decd`

## 背景

柱子森林:执行失败后仍查学习表,已经垫好的柱子被表标贵(写下的悲观值对自建的地形必然过期),按估价提交的半程逃到隔壁没记账的一列,
每失败一次横移一根——三秒四根六格高的柱子。这是实时搜索文献里写明的固有震荡(scrubbing)。

## 决定

先按重启的类型分开换表;接着用生产预算审了一遍:深井、两个口袋、三个深井不靠学习表单次就能搜完。学习表整条删掉(表、写回、估价里的消费、换表),
搜索唯一参考的记忆是世界本身。同一天定"长期稳定路线 v3"五条原则:确定性优先、记忆只住在世界与任务层、一份到达语义、结构胜过预算、失败必须上抛。

## 后果

- 柱子森林在结构上不再可能;行为可复现、故障可复盘。
- 洼地类地形只能靠更大的预算(0006)或粗层(v3 第二期,见 0021)。
- 0.1.5 又用了学习(0020),但只从搜索边界往里抬、抬过的仍是下界,执行失败另记"这一步不通",只活这一趟——柱子森林的成因不再成立。
