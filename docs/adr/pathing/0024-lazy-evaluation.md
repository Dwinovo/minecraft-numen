# 0024 惰性评估:候选乐观估价,取出时才精确判

- 状态:已接受;修订 0019(快判断)
- 日期:2026-10-28

## 背景

0019 的快判断只在"平地站着不改地形"时答成立;挖、放、半砖、楼梯、水、梯子一律交给精确判断,而精确判断在每个**生成**的候选上跑。
一次搜索生成的候选是展开节点的十几倍,绝大多数从未被取出。

## 决定

1. 快判断四种答复:`REJECT`(必然不成立)、`HOLDS`(必然成立,落点与代价精确)、**`LIKELY`**(由标志字与按方块状态预算的表给出**乐观代价**:
   不高于精确代价;落点按标志字定)。不再有"交给精确判断"这一答。
2. `LIKELY` 的节点标"未核"进开放集。**取出时**对它进来的那一步做精确判断(读父节点那条路叠了改动的世界):
   - 不成立:丢掉,原因进收场诊断;
   - 成立、真价高于估价:按真价放回开放集;
   - 成立、真价不高于估价:标"已核",展开。
   这是 Lazy Weighted A* 的规则。交出的路线(含半程)上每一步都已核,不另设"出发前精判"。
3. 乐观估价的判据仍从精确几何与语义推出(0011:几何只从碰撞箱推一份),不另立一套。挖:距离够不够、挖掘刻数(按方块状态 × 工具查表)、会不会塌、
   挨着流体;放:周围五个方向有没有能贴着放的整格。
4. 权限仍在搜索里裁决,但**同一次搜索里同一格、同一种改动、快照里没改过的格只问一次**,结论缓存在搜索作用域;被这一路改过的格照问。
   缓存在 `pathing` 侧包住 `TerrainPolicy` 端口,权限层本身不动。
5. 两条单测不变式,随机世界上逐节点、逐走法、逐方向对精确判断核对:`REJECT` ⇒ 精确不成立;`LIKELY` 的代价 ≤ 精确代价。

## 依据

Lazy Weighted A*(Cohen, Phillips, Likhachev, RSS 2014);LazySP(Dellin & Srinivasa, ICAPS 2016);Lazy Receding-Horizon A*(Mandalika, Salzman, Srinivasa 2018);
Baritone `PrecomputedData`(按方块状态预算"能踩、能穿、说不准"三态)。

## 后果

- 精确判断的次数从"生成数"降到"展开数"。
- 乐观过头的走法会让取出时不成立的比例升高、白忙;按走法统计这个比例,超标就收紧那种走法的乐观估价。
