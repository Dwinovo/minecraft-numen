# 0005 对话里不再标日期,右下角的消息通知不要了

- 状态:已接受,已落地(待真机看)
- 日期:2026-11-26
- 修订:[0001](0001-process-line-and-no-message-clock.md) 第 6 点("日期分隔照留")、[0003](0003-status-dot-not-unread-count.md) 第 3 点(消息通知用同一个状态点)

## 背景

气泡下的时刻去掉以后(0001),对话里还剩日期分隔:每换一天插一枚"今天""昨天""11月20日",对话全是今天说的,顶上也挂一枚"今天"。
没开面板时她说话,右下角还会弹一张消息通知卡片。用户:"今天那个我感觉可以去掉了,没必要,就是不用显示时间的";
"右下角的 UI 可以完全去掉了,已经有聊天框所以没有必要搞那个"——她的话本来就会进原版聊天栏(和头顶气泡)。

## 决定

心智模型:**对话里不显示任何时间;她在你没开面板时说的话,看聊天栏和她头顶,不另弹卡片。**

1. 删掉日期分隔:对话流里不再插日期牌,"今天""昨天"与日期格式的翻译键一并删掉(没有别的用处的话)。
2. 删掉右下角的消息通知:卡片本身、它的排队与合并、它的设置项(若有),以及只为它存在的接线。
3. 她在面板外说的话照旧进原版聊天栏、显示在头顶气泡;她用 `AskUserQuestion` 问你时,照旧在聊天栏留一行(control 0028)。
4. 状态点(0003)只剩左栏与转盘两处。

## 后果

- 对话更干净,屏幕右下角不再被占。
- 没开面板时只能从聊天栏与头顶气泡知道她说了话;要看全文开 G 面板。
