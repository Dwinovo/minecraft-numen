# 0006 界面照新原型重做:原型是权威,圆角、矢量图标、立体方块头、自己的缩放

- 状态:已接受
- 日期:2026-11-28
- 修订:[0004](0004-her-replies-are-plain-text.md)(她的话回到气泡)、`docs/ui-design-rules.md`(不再"只画方角")
- 另见:[0001](0001-process-line-and-no-message-clock.md)、[0002](0002-welcome-screen.md)、[0003](0003-status-dot-not-unread-count.md)、[0005](0005-no-dates-no-toasts.md)

## 背景

- 11-26 起做了一份全新界面的网页原型,11-28 又照 Grok Bot 的录屏逐条调过:可收起的左栏、浮在上面的名字胶囊、点胶囊滑出的资料面板、
  立体方块头像的悬停与忙碌动效、在资料面板里换模型和思考档位、自己的界面缩放。
- 原型:`D:\01_Projects\numen-design\fresh-ui-2026-11-26\index.html`(在线版 https://claude.ai/artifact/GkvP6vDHa1je3jBxrx7c4z)。文件开头的
  "design rationale"十二条与 CSS 里的注释是设计说明。
- 用户:"游戏里面就照着这个 UI 做吧";"这个 demo 是权威";"那些 icon 可以用贴图,SVG 什么的……像素的 icon 还是太丑了";"兼顾性能与效果"。
- 现在的 `ui` 模块只会画方角矩形、文字和裁剪,图标是 12×12 的像素图(pixelarticons),头像是平面的脸。原型要的圆角、半透明底、矢量图标、立体头像画不出来。

## 决定

心智模型:**原型怎么长、怎么动,游戏里就怎么长、怎么动;画不出来的先补画布,不在屏幕里拼凑。**

1. **原型是唯一的权威。** 布局、尺寸(原型里的 px 就是 GUI 像素)、圆角半径、颜色、文案、动效曲线与时长照原型;原型与旧 ADR 冲突时以原型为准。
   她的话回到气泡(修订 0004)。原型里没有的东西不加。
2. **画布补三样,都进 `IDrawSurface`,组件库仍不碰 MC:**
   - 圆角矩形(填充与描边,半径按原型),在物理像素上画得平滑:着色器或按缩放烘好的九宫格,由实现决定,接口只有一个。
   - 矢量图标:**图标与厂商标志的唯一来源是 SVG 文件**(资源目录里一枚一个文件;厂商标志来自 models.dev,随 models.dev 快照一起更新,
     单色 `currentColor`,MIT)。在客户端按实际物理像素栅格化成白色贴图、按 (图标, 物理尺寸) 缓存,着色后贴;界面缩放一变就按新尺寸重烘。
     删掉 pixelarticons 那套像素图标与转换脚本。
   - 立体方块头:用她的皮肤贴图(头与帽子层)画一个六面的立方体,能转、能缩放、能上下浮动。
3. **动效。** 一个纯 JVM 的弹簧(位置、速度、刚度、阻尼)放在 `ui` 模块,头像的转向、缩放、浮动都用它;一般过渡用原型的那条曲线
   (0.32/0.72/0/1,160/320/480 ms)。减少动效的设置打开时直接到位。
   - 悬停:鼠标在她那一行(或资料面板的大头像)上时,头朝鼠标转,上下 ±26°、左右 ±32°,略放大、上浮;移开带弹性回正。
   - 忙碌(她在想或在干活):头缩成小方块,像掉落物一样自转、上下浮动,下面一团影子;闲下来转回正面、"啵"地长回原样。
4. **自己的界面缩放。** 游戏的界面尺寸只管原版的东西;Numen 的面板、快捷输入、按键说话条用自己的缩放:游戏 2 → 2,3 → 2.25,4 → 2.5
   (`2 + (s − 2) × 0.25`,小于等于 2 时跟游戏一样)。实现上是在我们的屏幕里按 `我们的/游戏的` 再缩一次,布局用我们自己的虚拟尺寸。
   非整数倍时像素字会不匀,要真机看效果再决定是否改成整数档。
5. **分两批做,一批一个执行者:**
   - 第一批:画布三样、弹簧、立体头像、自己的缩放;聊天页整页照原型(可收起的左栏与底部"新同伴/设置"、名字胶囊、资料面板与其中的模型列表和思考档位、
     对话与气泡、过程那一行去掉步骤小圆点、输入框)。
   - 第二批:设置各页、召唤页、快捷输入、按键说话条、头顶气泡与其余 HUD,照原型。
6. **换模型与思考档位是每只同伴自己的**,只在资料面板里换;全局的厂商与钥匙仍在设置里。思考档位沿用引擎的 `ThinkingLevel`(自动、关、低、中、高、最高),
   原型只画了后五档,"自动"放在哪一档由执行者照原型的样子补上并在实现说明里写明。

## 后果

- 界面与原型一致,改样子先改原型再照着做。
- `IDrawSurface` 多出三种画法;移植到其他版本分支时,适配层要各写一份。
- 图标从像素图换成矢量图,任意缩放下都清楚;新增图标只放一个 SVG 文件。
- 头像要能拿到她的皮肤贴图;没有皮肤时用默认皮肤画同一个立方体。
