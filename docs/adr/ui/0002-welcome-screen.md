# 0002 和她还没说过话时,聊天区是一屏招呼:大头像、名字、一句话、几个能点的建议

- 状态:已接受,已落地(待真机看)
- 日期:2026-11-26
- 另见:[0001](0001-process-line-and-no-message-clock.md)

## 背景

新同伴的会话打开时,聊天区只有顶上一条服务消息"对 某某 说点什么。"和一大片空的点纹底,看着像没加载出来。用户:"这个首屏得改改";
看过演示(现在的配色与方角里只换这一屏)后:"可以改吧"。

## 决定

心智模型:**和她还没说过话,聊天区正中就是她在跟你打招呼;你一开口,这一屏就换成对话。**

1. 只在会话里一条可见消息都没有时出现(和现在的空提示同一个判据,只换画法)。
2. 正中竖排:她的大头像(皮肤的脸,和左栏同一张)、名字、一句招呼("今天想一起做点什么?")、一行可点的建议。
3. 建议四条,固定文案,走翻译:跟着我、附近有什么、帮我砍点木头、看看你的背包。点一条就是主人把这句话发给她,和在输入框里打字发送走同一条路,
   不另开发送口。
4. 群聊会话不出这一屏,照旧空着(群里说话的人不止一个,建议发给谁说不清)。
5. 删掉的:顶上那条"对 某某 说点什么。"空提示。
6. 出现与消失带过渡,不硬切;配色、方角、字照现在的主题。

## 后果

- 新同伴第一次打开就知道能做什么、点一下就能开始。
- 演示:`numen-empty-demo`。
