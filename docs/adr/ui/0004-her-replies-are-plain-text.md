# 0004 她的回复不包气泡,正文铺到右边;只有主人的话是气泡

- 状态:已接受,已落地(待真机看);被 [0006](0006-fresh-ui-from-the-demo.md) 修订,她的话回到气泡
- 日期:2026-11-26
- 另见:[0001](0001-process-line-and-no-message-clock.md)

## 背景

现在主人与她的话都是气泡,她的长回复被框在左边七八成宽里。主流的 AI 产品(ChatGPT、Claude 等)都是用户的话是气泡、模型的回复是正文,
从左铺到右。用户看过演示后:"UI 暂时还是先不改了,你就把 AI 的回复气泡去掉,改成可以顶到右边吧,就是参考主流的情况"。

## 决定

心智模型:**你的话是气泡,她的话是正文。**

1. 她的话不画底色与框,正文从聊天区左边距一直排到右边距,宽度和聊天区一样(左右各留现有的内边距)。
2. 主人的话照旧是右边的气泡,样子不变;背景、配色、方角、过程那一行、清单消息、征询卡都不变。
3. 群聊里她们的话前面照旧写名字(连发只写第一条),因为不包气泡后靠名字分谁说的;私聊不写名字。
4. 原来挂在她气泡上的东西跟着正文走:引用回复的引用条、流式打字的光标、点选与引用回复的点击区域。
5. 删掉的:她的气泡底色与框的画法,以及只为它存在的颜色与尺寸。

## 后果

- 长回复读起来像正文,屏幕上少一半的框。
- 群聊靠名字区分说话的人。
