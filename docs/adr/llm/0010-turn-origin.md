# 0010 回合记住出处,换模型后不回塞上一家的私货

- 状态:已接受
- 日期:2026-09-20
- 提交:`885d8ce37`

## 背景

`extras` 与思考内容会原样回传(llm 0002、0008)。档案中途换了厂家或型号,上一家的私有字段、思考签名被塞给下一家,下一家拒收或行为异常。

## 决定

照 pi-mono 的判据(厂家与接口都相同才回传):每条 `AssistantTurn` 记下出处(适配器与型号),随会话落盘;组请求时出处对不上,
就脱掉这一条的 `extras` 与思考内容,只留正文与工具调用。

## 后果

- 换模型不再坏掉多轮对话;代价是换模型后上一家的思考不再带过去,这本来也带不过去。
