# 0007 模型接入独立成纯 JVM 模块 `ai`

- 状态:已接受
- 日期:2026-08-02
- 提交:`54d221e4e`、`22571b6ba`

## 背景

传输、提示词、厂家适配原来和 Minecraft 代码混在一起。而十几个 Minecraft 版本分支,厂家接入这部分其实完全相同,修一处要改十几份。

## 决定

照 pi-mono 的分包思路,把变化频率与依赖方向不同的代码切开:
- `ai` 模块零 Minecraft、零 Numen API 回引,与 Minecraft 版本无关;
- 装:传输(SSE、重试、看门狗)、提示词、厂家适配、会话与压缩、`ProtocolView`;
- 发行时平铺进加载器 jar,发布坐标 `com.dwinovo.numen:numen-ai`,不带 Minecraft 版本后缀。

## 后果

- 厂家层的修复改一处,所有版本分支共用。
- `ai` 能脱离游戏单测(当时首批 62 条)。
- 档案库与设置界面在客户端,不在 `ai` 里;`ai` 只认解析好的 `LlmEndpoint`。
