# 0018 已弃用的型号读目录时就丢掉,不提示

- 状态:已接受
- 日期:2026-10-14
- 提交:`2e7fa7232`

## 背景

models.dev 给已弃用的型号标 `status: deprecated`。界面原来照列,选厂家时还会默认选中第一个能调工具的型号,
DeepSeek 选中的正是已弃用的那个;中间草图试过加"已弃用"提示,用户否了:"弃用了就直接不显示,让他自己自定义就行"。

## 决定

- 读目录时就丢掉已弃用的型号,界面不显示、不提示;随包快照里仍保留 `status`,读入时才丢。
- 档案里正在用的老型号当作手填的型号照常用,能力未知,思考只给"自动"。

## 后果

- 型号列表只剩能用的;老档案不会因为型号弃用而突然坏掉。
