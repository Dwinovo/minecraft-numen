# 0011 消息配对只在 ProtocolView 一处修

- 状态:已接受
- 日期:2026-09(智能体循环重做)
- 另见:`docs/agent-loop.md` §九

## 背景

各家都要求消息序列合法:工具调用要有对应的结果、user 与 assistant 交替。打断、失败、断线会留下悬空的调用或相邻的 user,
原来在四处各补一刀,三种文案。

## 决定

`ProtocolView.forWire`(`ai` 模块)在转成厂家格式前,把会话统一修成合法序列:悬空的调用补一条结果、被打断的回复说明为什么、相邻的 user 合并。
这是全仓唯一一处;适配器只翻译,不修序列。

## 后果

- 任何协议都拿到合法的序列;新协议不用各自再修。
