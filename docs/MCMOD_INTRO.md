# MC百科条目正文草稿(营销开场 → 大饼 → 玩法机制)

> 提交前删掉本行说明。全文原创,与 GitHub README 无重合段落。

每一个 Minecraft 玩家都做过这样的梦:身边有个真正靠谱的搭档——你负责想,它负责干;你去探险,它看家、挖矿、盖房;你说一句话,事就办成了。

言出法随 (Numen) 把这个梦做成了模组。召唤一名由大语言模型驱动的同伴,像跟朋友聊天一样吩咐它:

- "去挖一组铁回来"——它自己规划路线、下到矿层、换上合适的镐子,满载而归还追问一句:要不要顺手熔了?
- "在我站的地方盖个小屋"——地基一块块垒起来,门窗火把一样不少;
- "咱们去打末影龙"——它知道先下地狱拿烈焰棒,知道末影珍珠去哪换,知道要塞怎么找。屠龙的整套攻略,它出厂就背熟了。

它是这个世界里的**真玩家**:挖掘有真实的速度与工具判定,战斗有真实的冷却与暴击,会被苦力怕炸、会触发压力板、能打开任何机器的界面。峡谷和岩浆拦不住它——搭桥、搭柱、挖隧道、游泳,它自己修路过去。受伤了自己吃东西,快淹死了自己上岸,死了掉落照旧、缓一会儿在你身边重生。它还有记性:你们共用的箱子、熔炉、工作台,它都记得位置,跨存档也忘不掉。

近三十种能力、十篇内置攻略、任意 OpenAI 兼容模型随便挑(DeepSeek、Kimi、通义千问、豆包都行)——用你自己的 API Key,想用多聪明的脑子,你说了算。**从 1.20.1 到 26.1.2 共 11 个游戏版本,Fabric / Forge / NeoForge 三家加载器全覆盖**,你在哪个版本玩,它就在哪个版本等你。

## 它要去的地方

原版只是它的新手村。作者给这个模组画的图纸大得多:

- **玩转一切模组**。它的身体本来就能挖、能放、能右键任何模组的机器,甚至隔着外壳看清里面装了多少物品、流体、能量。配上为机械动力(Create)、应用能源 2(AE2)、Mekanism 定制的兼容模块和攻略,未来对它说一句"建一套自动化铁工厂",它真能跨模组给你搭出来;
- **一篇 Markdown 教会它任何玩法**。技能系统零代码、纯文本,谁都能写——社区一起攒一座技能库,每个模组的玩法都能变成它的本事;
- **把手伸出游戏**。它的能力接口天生不挑对象:玩家离线时,它在 Discord 上汇报基地状况;开直播时,弹幕轮流指挥它干活;通过 MCP,电脑上的 AI 助手还能反过来操作 Minecraft 世界;
- **让所有模组都能长出 AI**。驱动它的引擎已拆分为独立项目 numen-api 并向所有开发者开放——AI 村民、剧情 NPC、服务器 AI 管理员,都能在这套系统上造出来。

以上蓝图中,多版本多加载器与引擎开放已经落地,其余正在开发。

## 玩法与机制

同伴是服务端的假玩家(`ServerPlayer`)实体,所有行为都经由原版玩家的代码路径执行,与世界的交互规则和真实玩家完全一致。

模组为大模型提供了近 30 个"工具"作为感知和行动接口:

- **行动类**:寻路移动、挖掘、放置、近战与弓箭战斗、进食、装备、丢弃与转移物品、操作任意容器/机器 GUI、按配方合成、熔炼;
- **感知类**:自身与主人状态查询、范围方块/实体扫描、单方块检视、配方查询、结构与群系定位,以及不打开界面直接读取机器内容物(物品、流体、能量)的"透视"能力;
- **规划类**:任务清单管理、等待、技能加载。

每次工具执行后,其结果(包括失败原因,如"徒手无法挖掘铁矿石,至少需要石镐")会以自然语言反馈给模型,模型据此调整后续行为——同伴会在试错中越玩越熟练。

寻路系统为假玩家场景独立编写;对话记忆跨存档持久化,过长时自动压缩。

## 技能(Skill)系统

技能是用 Markdown 纯文本编写的攻略文档,只在与当前任务相关时才注入提示词。模组自带 10 篇覆盖原版主线的技能(工具升级路线、下界、烈焰棒、末影珍珠、要塞定位、屠龙准备等)。

玩家可以在 `config/numen/skills/` 目录下新增或修改技能;与内置技能同名的文件会覆盖内置版本。用它来立下自己服务器的规矩,或教会同伴一个新模组,都只是写一篇文档的事。

## 使用方法

1. 安装本模组(Fabric 版另需前置 Fabric API),进入存档;
2. 按 `G` 打开面板,在 **Settings** 页选择服务商、填入自己的 API Key 和模型名;
3. 点面板左栏的 **`+`** 召唤同伴并命名;
4. 点击同伴头像进入 **Chat** 页,用自然语言下达指令。

面板共三页:Chat(聊天与实时任务计划)、Items(同伴物品栏与装备查看)、Settings(密钥与模型设置)。左栏为同伴列表,支持多同伴切换、召唤与注销;屏幕左缘另有头像 HUD,同伴说话时会弹出气泡。

## 注意事项

- 本模组不内置 AI 服务:需自行准备兼容 OpenAI 接口的大模型 API Key 并联网,未配置时 AI 功能不可用;
- 模型调用从每位玩家自己的客户端发起、各自计费,服务器不经手密钥;
- 同伴执行任务的效果与所选模型的能力直接相关。
