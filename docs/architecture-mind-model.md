# numen 心智模型宪法

一个同伴 = 一具身体(服务端)+ 一个大脑(客户端 LLM)+ 两个消息口。
任何新功能必须能在本文档里找到自己的位置;找不到,先修宪再动工。

## 一、身体层:每 tick 一次竞价

所有想控制身体的机制都是 `TaskChain`,每 tick 向 `CompanionBrain` 出价
(`getPriority`),最高价独占身体,被抢占者收到 `onInterrupt`。

```
MLG(10) > 反击/逃跑(5) > 进食(4/3) > 脱困(2) > 穿甲(1) > LLM 任务(0)
└──────────────── 本能(硬编码,不花 token)────────────┘   └ 认知 ┘
```

- LLM 是出价最低的竞价者:任何本能都可随时抢走身体,完事归还。
- LLM 链内部按模型 tool call 的先后顺序执行任务(FIFO 只存在于这条链内部)。
- 不需要独占身体的自动行为(挖矿换工具、食物过滤、索敌过滤)不是链,
  是任务执行中被咨询的纯函数策略——没有 tick,没有优先级,不参与竞价。

## 二、大脑层:事件驱动,平时不在场

LLM 不在 tick 循环里。它只在三种时刻运转:主人说话、外部消费者显式唤醒
(核心域不使用)、自己的工具结果回来。它对身体的全部控制 = 向 LLM 链投任务。

## 三、模型输入全景:四层,动态口只有两个

```
A. 静态框架(每 turn 组装) A1 系统提示词 = 基座指令 + persona(+反射总览/语言指令,规划中)
                            A2 工具表(schema + description)
B. 历史                     B1 对话历史(ConvoLog 回放)
                            B2 压缩摘要(上下文过长时替换旧历史)
C. 本 turn 新输入(user 侧)C1 主人消息(含忙时缓冲)
                            C2 ambient 事件:攒着,下个 turn 一并注入
D. turn 内回填(tool 侧)   D1 任务工具结果
                            D2 查询工具结果(get_self_status 等,拉取语义)
```

**动态注入口仅 C2 与 D1。核心域 C2 无紧急档。**
`emitEvent(xml, urgent)` 的 urgent 参数保留为公开 API 能力,仅供外部
交互型消费者;核心自身永远传 false。

**唤醒经济学(urgent 的裁决口诀)**:"这次唤醒在替谁花钱?"
替任务花(存在悬置 turn)→ D1 本来就会送达,无需唤醒;
替身体花 → 本能链应对,与模型无关;
替陪伴感花(主动打招呼/日程/同伴互聊)→ 产品功能,走 urgent API、
配开关、主人决定——即使实现在核心仓库里,也按"外部型消费者"接入,
不进 BodyLog、不修本宪法。

## 四、身体叙事:BodyLog 双轨路由

身体自己干的一切事(本能动作、抢占经过、死亡叙事、换维度)只有一个收口:

```
Reflex.report(id, 人话)  →  BodyLog(每同伴,有界队列)
    ├─ 有活跃 LLM 任务:入队,随该任务结果发货(D1 尾部 [meanwhile...])
    └─ 闲时:立即包成 ambient 事件(C2),下个 turn 送达
```

- 单次排干:两口共享队列,谁先到谁拿走,不重复。
- 兜底冲刷:任务无结果终止(如死亡丢弃)时,滞留条目转投 C2。
- 死亡叙事无特权:工作中死亡由"恢复的 turn"送达(打断的工具调用在复活时
  收到失败结果,悬置 turn 自然继续);闲时死亡等下次输入。主人的知情由
  vanilla 死亡广播保证,与模型无关。
- 判定口诀:"这段文字是身体替自己写的日记吗?"是 → BodyLog;
  不是 → 各回各家(工具结果本体、主人消息、状态快照、静态框架)。
- **核心代码永远不直接调 emitEvent,一律 report 进 BodyLog**——核心域内
  ambient(C2)的唯一内容生产者是 BodyLog,ambient 只是它闲时出口的运输方式;
  emitEvent 作为公开 API 保留,仅供外部模组直接插入。

## 五、显式意图:钉(pin)

反射提供默认,显式意图压过反射,认知层管理例外的生命周期。

- **落钉**:模型/主人显式 `equip_item` 即为意图声明,自动落钉,无需新指令。
- **归还**:`equip_item` 的 item 取值 `"auto"` = 解除该槽位的钉,反射恢复。
- **过期**:四个自然终点——显式更换或归还 / 物品损坏 / 物品离开槽位 /
  主人姿态开关关闭整条链。**刻意不设定时器**:钉对认知层可见
  (`get_self_status` 标记 + 让位日记),陈腐意图由模型自己清理。
- **可见性**:反射因钉让位时记一次日记(去抖);工具卫兵拒绝显式请求时,
  失败消息必须附带解除方法(拒绝时教学)。

## 六、Reflex(本能)登记处

Reflex 不是运行时概念,是自动机制的入职契约:

```java
interface Reflex {
    String id();        // "auto_armor"
    String describe();  // 一行自述,汇入系统提示词反射总览
    // report(人话) 经 BodyLog 路由;通道与紧急度永远不由反射决定
    // enabled() 姿态开关由 Registry 统一管理(持久化,主人可关单项)
}
```

- 执行形态各归各位:要身体的 implements TaskChain(照旧),
  纯策略只 implements Reflex。没有第二个调度器。
- 新机制的接入成本 = 机制本身的逻辑;自述进提示词、动作进 BodyLog、
  姿态开关、尊重钉,全部由登记处自动获得。

## 七、检验:新功能四问

1. 要不要独占身体?→ 是:新竞价链,定优先级;否:纯函数策略。
2. 是模型发起的吗?→ 是:LLM 链里的任务,消息走 D1。
3. 是身体自己发生的吗?→ 是:report 进 BodyLog,双轨自动路由。
4. 模型需要预先知道这机制吗?→ 是:实现 Reflex,自述自动进提示词。

四问答完仍无处安放的功能,先修宪再动工。
