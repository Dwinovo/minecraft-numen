# Numen 界面规则

改界面先对照这一页。每条都写了照谁做,拿不准就回去看参照对象本身。

## 参照系

| 管什么 | 参照 | 取什么 |
|---|---|---|
| **外壳** | Discord | 左栏是会话(带选中条的头像列、底部 `+`)、抬头是名字 + 右侧一排图标、底部输入行左 `+` 右图标、成员栏、模态卡;拿不准怎么摆就开 Discord 看 |
| **正文与操作习惯** | Telegram Desktop | 气泡:自己在右、别人在左,群里别人的气泡带名字和头像;私聊和群同一套;连发合并只画一次头像;日期分隔线;时间戳贴在气泡角上;回车发送、Shift+回车换行、点开的东西 Esc 收回;拿不准怎么排、怎么按就开 Telegram 看。不照 Discord 的平铺行——那是几百人频道的密度,我们是一两只同伴的私聊 |
| 视觉 | 原版 Java 版 MC;模组圈的通行做法(Jade、WTHIT、JEI、REI) | 方角、细描边、深色半透明底——Discord、Telegram 的圆角与配色都不取 |
| 现代化处理 | Mojang 的 Ore UI(基岩版的设计系统) | 扁平、方角,仍然是 MC |
| AI 同伴的状态 | inZOI 的 Smart Zoi | 状态挂在角色头顶;细节点开才看 |
| AI 同伴的交流 | PUBG Ally、Player2 AI NPC | 说话为主,屏幕上少加东西 |
| 当场做决定 | 游戏里的组队邀请、交易请求、准备确认 | 谁、要做什么、选项、倒计时条 |
| 问答时的输入 | pi(`interactive-mode.ts` 把编辑器整个换成选择框) | 问答挡住输入框,答完才回来 |

## 形状

- **方角,不画圆角。** 框 = 一圈 1 像素描边 + 内衬底,唯一的画法是 `NumenStyle.box`。
- 层级靠颜色、描边、间距;块与块之间用一道横线分开,不用再套一层框。
- 聚焦、悬停、出错只换描边色,不换形状。

## 对齐

方角下差一两个像素都看得出来,所以位置不各算各的:
- **容器里一圈内边距**:容器描边、分隔线到里面东西的距离都是同一个值(`NumenStyle.PAD`);分隔线上下贴容器描边。
  侧栏的选中底、分区的抬头、列表的边沿都落在这一圈上。
- **抬头行与收尾行和控件同高**(`NumenStyle.HEADER_H`):标题、开关在行内垂直居中(`centerIn`),按钮与行等高、
  贴行的边;正文从 `bodyTop` 开始,收尾按钮从 `footerTop` 开始。侧栏的行高也是这个高,侧栏第一行与右边的抬头行上下齐。
- 选中底与它旁边的强调竖条同高。

## 信息量

- 默认少,细节在选中或展开时出现(答复框里要记下的规则只在选中"以后都允许"时出现)。
- 能用界面元素说的不写字:剩余时间画成缩短的条,撤不回用警示色,别的条目数用"+N",方块和物品画图标。
- 实体、没有图标的东西照写名字;理由缩成短词。
- **行内动作用图标 + 悬停一句话**（GHOST `Button` + `icon()` + `tooltip()`，如复制、重新生成）；**页面级的落地动作写字**（保存、保存并重启、复制接入提示词）。有后果的动作不靠“写成字”挡，靠确认卡挡。
- **图标是 12×12 的纯白贴图**（`assets/.../sprites/icon_*.png`），白色乘任何颜色就是那个颜色，所以常态/悬停/置灰/危险各是一次着色，不为每种状态存一张。
  形状不自己发明：从 pixelarticons（MIT，本就按 12×12 像素格画）用 `api/tools/ui-textures/pixelarticons.py` 转过来，不重采样；出处与授权写在 `LICENSE-ASSETS`。
- **贴图在 MC 层，几何与状态色在 ui 层**：控件只拿到一个 `IconDrawer`（见 `Button.icon`），怎么把那块颜色画出来是 `client.ui.mc.Sprites` 的事。

## 入口

- **一个分区一页说完，不藏子页。**多一层导航的代价是主人得先发现那个按钮能点。
- **默认只给新手要用的那几件，高级的收进倒三角**（`Disclosure`，默认收着）。
  一屏装不下就上下滚（`ScrollBox`）——不为了不滚动而把行挤在一起，挤得认不出哪个标签配哪个框。
- **改与删是并排的两个入口。**名字旁边铅笔改、红垃圾桶删；删一律过确认卡——危险靠确认挡，不靠把入口藏起来。

## 同伴状态与通知

- **同伴自己的状态住在头顶气泡**:她说的话在上;状态行在下——等你点头(强调色)、正在做什么、正在思考。
- **系统提醒走右上角 toast**(`NumenHudToasts`):
  - 位置和停留照原版——右上角,排在原版 toast 下面;至少停 5 秒,乘原版"通知显示时间"。
  - 文案照原版教程的句式"xxx,按 [键] 做什么",键名取自按键绑定。
  - 只报要主人知道的事(有请求、请求撤回、没连上);主人自己刚做完的事不报。
- **聊天框是日志**:主人说的、同伴说的、要留痕的失败。

## 当场做决定

- 问答**替换整条输入行**,与输入框同级:占整行宽度,旁边的键不画,上面的对话流往上让位;不做叠在上面的弹层。
- 选项带序号,选中的那项多一个箭头;数字键直接选。
- "说一句"就是选项里的输入框本身(输入行自己那一个),不另开框。
- 有撤不回的事时不给默认选中。

## 分层

- **ui 模块(纯 JVM)**:控件、样式令牌(`NumenStyle`、`NumenTheme`)、画布契约 `IDrawSurface`——只有矩形填充、文字、测量、裁剪。
- **MC 层**(`api` 的 client 源码集):`McDrawSurface` 适配器、真输入框宿主 `McTextInput`、各个屏幕。
  屏幕画框也经 `McDrawSurface` 调 `NumenStyle.box`,不自己拼样式;只有 MC 独有的东西(物品图标、皮肤脸、世界里的轮廓)在 MC 层直接画。
